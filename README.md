# 🚀 Демонстрация Мемоизации в React (ДЗ 50.1)

Этот проект создан для демонстрации методов оптимизации производительности в React с использованием мемоизации.

## 🛠 Реализованные технологии оптимизации:

### 1. `React.memo`
Используется для компонента `ExpensiveList`. Это компонент высшего порядка, который предотвращает повторный рендеринг компонента, если его пропсы (в данном случае список элементов) не изменились.

### 2. `useMemo`
Используется для фильтрации списка товаров. Тяжелая операция фильтрации массива выполняется только тогда, когда меняется текст в поле поиска или сам список, но **не** выполняется при обновлении счетчика в другом конце страницы.

### 3. `useCallback`
Используется для функции `handleIncrement`. Мемоизация функции позволяет избежать её пересоздания при каждом рендере `App`, что в сочетании с `React.memo` в дочернем компоненте `ChildButton` полностью исключает лишние перерисовки кнопки.

## 🚀 Запуск проекта
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

## 📈 Как проверить работу?
1. Откройте консоль разработчика (F12 $\rightarrow$ Console).
2. Введите текст в поле поиска $\rightarrow$ вы увидите сообщение `Running heavy computation (useMemo)`.
3. Нажимайте на кнопку "Увеличить счетчик" $\rightarrow$ вы заметите, что сообщение о пересчете списка **не появляется**, а кнопка **не перерисовывается**. Это и есть эффект мемоизации.
